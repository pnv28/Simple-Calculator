# Simple Calculator

Hello Everyone, I like coding so I made this

Below there are Instructions, telling how to Install this.

// Requires Node.js

To keep it in your computer use the Following Command
>git clone https://github.com/pnv28/Simple-Calculator

To Enter it use
>cd Simple-Calcilator

Run the following command after that
>npm i

Finnaly to run it use
>node main.js
